# quiz-master-app
It is a app that acts as an exam preparation site for multiple courses.

This project involves creating a platform with two roles: Admin (the superuser who 
manages subjects, chapters, and quizzes) and User (who can register, attempt quizzes, and view 
scores). The Admin creates subjects, chapters, and quiz questions, while Users can select a 
subject, take quizzes, and track their performance.

## Tech Stack
- **Backend**: Python, Flask
- **Database**: SQLite (via Flask-SQLAlchemy)
- **Frontend**: HTML, CSS, Jinja2 templating, Bootstrap
