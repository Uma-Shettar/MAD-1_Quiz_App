# quiz-master-app
It is a app that acts as an exam preparation site for multiple courses.
## Tech Stack
- **Backend**: Python, Flask
- **Database**: SQLite (via Flask-SQLAlchemy)
- **Frontend**: HTML, CSS, Jinja2 templating, Bootstrap
